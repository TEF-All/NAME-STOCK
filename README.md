# ระบบ Stock สำเร็จรูปพร้อมใช้งาน

ระบบคลังพัสดุสำหรับหน่วยงาน ใช้ของฟรีทั้งหมด: **Google Sheets** (ข้อมูล) + **Google Apps Script** (หลังบ้าน) + **GitHub Pages** (หน้าเว็บ)
Ready-to-use inventory system template (Thai / English UI) — no data included.

**เริ่มติดตั้ง → [docs/คู่มือติดตั้ง.md](docs/คู่มือติดตั้ง.md)** (ชีต → สคริปต์ → Deploy → config.js → GitHub Pages → ผู้ดูแลคนแรก)

## ทำอะไรได้

- ทะเบียนพัสดุ รูปภาพ ค้นหา ตะกร้าเบิก โหลดรายการเป็น Excel
- แบบฟอร์มพิมพ์ (ใบเบิก ใบจ่าย ใบย้าย ใบตรวจนับ) ตั้งหัวกระดาษ ชื่อใบ ช่องลงนาม และโลโก้เองได้ใน `assets/config.js`
- เบิก-คืน / จ่ายออก พร้อมขั้นตรวจ อนุมัติ ลงนามอิเล็กทรอนิกส์ พิมพ์ใบเบิก/ใบจ่าย
- รับของเข้า ปรับยอด ย้ายที่เก็บ ปิด/เปิดรายการ (ไม่ลบแถว ประวัติอยู่ครบ)
- ตรวจนับ: บันทึกผลนับ คงเหลือปรับตามยอดนับอัตโนมัติ ยกเลิกผลนับได้ แดชบอร์ดสรุป
- ผู้ใช้ 4 แบบ: ผู้ดูแล (ADMIN) เจ้าหน้าที่ (STAFF) ผู้ตรวจสอบ (AUDITOR) คนนอก (กรอกแบบสอบถามก่อน)
- เข้าสู่ระบบด้วยรหัสทางอีเมล หรือปุ่ม Google (ไม่บังคับ)
- สลับภาษาไทย / English

## โครงสร้าง repo

| ที่อยู่ | คืออะไร |
|---|---|
| `index.html` `home.html` `stock.html` `request.html` `my.html` `count.html` `dash.html` `admin.html` `survey.html` `privacy.html` | หน้าเว็บ (GitHub Pages เสิร์ฟจากโฟลเดอร์หลัก) |
| `assets/config.js` | **ไฟล์เดียวที่ต้องแก้** ฝั่งหน้าเว็บ: ลิงก์ API ชื่อหน่วยงาน โลโก้ หัวแบบฟอร์ม |
| `assets/api.js` `shell.js` `i18n.js` | ตัวเรียก API · แถบเมนูตามบทบาท · สลับภาษา |
| `apps-script/` | โค้ดหลังบ้าน Apps Script (คัดลอกเข้า script.google.com) · ค่าตั้งอยู่ใน Script Properties ดู `Config.gs` |
| `sheet/sheet-spec.json` | แบบชีตเปล่า 24 แท็บ (หัวตาราง สูตร รูปแบบ) · `Setup.gs` ใช้สร้างชีตให้อัตโนมัติ |
| `docs/คู่มือติดตั้ง.md` | คู่มือติดตั้งทีละขั้น |
| `tools/local-test/` | ทดสอบในเครื่องโดยไม่ต้อง Deploy (จำลองบริการ Google) |

## ความปลอดภัย

- repo นี้เปิดเผยได้: **ไม่มี**ข้อมูล รหัสผ่าน โทเคน รหัสลับ OAuth หรือรหัสชีต
- รหัสชีตและค่าตั้งอยู่ใน Script Properties ของ Apps Script เท่านั้น
- OAuth Client ID (ถ้าใช้ปุ่ม Google) เปิดเผยได้ · **ห้าม**ใส่ Client secret
- หลังบ้านตรวจตัวตนและสิทธิ์ทุกคำขอ · เรียกได้เฉพาะคำสั่งที่อยู่ในรายชื่อ (`Api.gs` → `callAllowed_`)

## ทดสอบในเครื่อง (สำหรับผู้พัฒนา)

ต้องมี Node.js 18 ขึ้นไป · ใช้ข้อมูลสมมติเท่านั้น (อีเมล @example.com)

```bash
node tools/local-test/e2e-api.js
```

```bash
node tools/local-test/server.js
```

แล้วเปิด http://localhost:8765/ · ผู้ดูแลทดสอบ `owner@example.com` · รหัสเข้าระบบล่าสุดดูที่ http://localhost:8765/__mail

## ที่มา

พัฒนาต่อจากระบบคลังพัสดุที่ใช้งานจริง ตัดข้อมูลและชื่อหน่วยงานเดิมออกทั้งหมด
แก้ไขที่รวมไว้: สำเนา Firestore ไม่แสดงยอดค้างหลังบันทึก · หน้าตรวจนับไม่แสดงรายการเลิกใช้ · ลบรายการแล้วหน้ารายการพัสดุอัปเดตทันที · โซนเวลาชีต Asia/Bangkok · ปิดรายการซ้ำไม่ลงประวัติซ้ำ
